# M. Junaid Khan – Portfolio (Next.js 14)

Run locally:  npm install && npm run dev  → http://localhost:3000

Deploy on Vercel:
1. Push this folder to a GitHub repo, then import it at vercel.com/new (framework is auto-detected as Next.js), or
2. Run `npx vercel` inside this folder.

Edit content in `app/page.js`; colours are CSS variables at the top of `app/globals.css`.
